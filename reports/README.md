# reports/

- `YYYY-WW.md`: εβδομαδιαία αναφορά του tracker (μόνο αθροίσματα).
- `tracker-state.json`: ποιες αλλαγές priority έχουν ήδη εφαρμοστεί ανά εβδομάδα (για να ξανατρέχει χωρίς διπλή αλλαγή).
- `usage.jsonl`: κάθε κλήση worker (agent, worker, διάρκεια, αποτέλεσμα).
- `worker-state.json`: ποιοι workers είναι σε cooldown λόγω ορίων χρήσης.
